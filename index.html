볼케이노 설치

이 파일 하나만 여시면 됩니다. 파이썬·영상 도구·받아쓰기·Claude Code·VS Code 를 알아서 깔고 볼케이노를 붙여 줍니다. 10~20분쯤 걸리고, 관리자 비밀번호는 묻지 않습니다.

이 컴퓨터는 확인 중… 으로 보입니다. 맞으면 그대로 아래를 따라 하시고, 아니면 맨 밑의 다른 쪽 보기를 누르세요.

설치 파일 받기 setup.bat · 이 파일 하나면 됩니다

받았습니다. 이제 딱 한 번만 더 누르시면 끝입니다.

  1. 브라우저 오른쪽 위 내려받기 표시(↓)를 누르면 setup.bat 이 보입니다. 그걸 두 번 누르세요. (내려받기 폴더에서 찾으셔도 됩니다.)
  2. 「이 파일은 위험할 수 있다」고 하면 [유지] 를 누르세요.
  3. 파란 경고창이 뜨면 [추가 정보] → [실행].

그다음은 손댈 것이 없습니다. 검은 창이 알아서 10~20분 동안 다 깝니다. 끝날 때쯤 로그인 창이 한 번 열리는데, 메일로 로그인만 하시면 됩니다.

누르면 이렇게 됩니다

  1. 파일 하나(setup.bat)가 내려받아집니다.
  2. 그걸 두 번 누르면 나머지는 전부 저절로 진행됩니다.

옆에 다른 파일을 같이 둘 필요가 없습니다. 이 하나면 됩니다.

설치 파일 받기 volcano-mac.zip · 두 번 누르면 저절로 깔립니다

받았습니다. 아래 네 번만 누르시면 끝입니다. 타이핑할 것은 없습니다.

  1. 받은 volcano-mac.zip 을 두 번 누르세요. 압축이 풀리면서 volcano-setup.command 가 옆에 생깁니다.
  2. 그 volcano-setup.command 를 오른쪽 클릭 하세요. (마우스 오른쪽 단추가 없으면 Control 을 누른 채 클릭)
  3. 나온 목록에서 [열기] 를 누르세요. 두 번 누르지 말고 꼭 오른쪽 클릭으로 여셔야 합니다.
  4. 「확인되지 않은 개발자」 경고가 뜨면 [열기] 를 한 번 더 누르세요.

터미널(검은 창)이 저절로 열리고 거기서 알아서 다 깝니다. 그다음은 손댈 것이 없습니다. 끝날 때쯤 로그인 창이 한 번 열리는데, 메일로 로그인만 하시면 됩니다.
다음부터는 경고가 안 뜹니다 — 처음 한 번뿐입니다.

누르면 이렇게 됩니다

  1. 꾸러미 하나(volcano-mac.zip)가 내려받아집니다.
  2. 두 번 눌러 풀고, 나온 파일을 오른쪽 클릭 → 열기 하면 터미널이 저절로 열리면서 나머지가 전부 진행됩니다.

터미널을 직접 찾아 열 필요 없습니다. 타이핑도 없습니다.

위 방법이 안 되면 — 한 줄 붙여넣기

터미널을 직접 여실 수 있는 분만 쓰세요. ⌘ + 스페이스 → 터미널 이라고 치고 엔터 → 아래를 붙여넣고 엔터.

[추가 정보] 를 누르면 아래에 [실행] 이 나옵니다. 서명을 안 산 파일이라 뜨는 것입니다.
검은 창이 한참 그대로예요
받아쓰기(whisper) 부품이 덩치가 커서 몇 분 걸립니다. 끄지 말고 두시면 됩니다.
중간에 멈추거나 빨간 글씨가 났어요
같은 파일을 한 번 더 두 번 누르세요. 이미 깔린 것은 건너뛰고 못 깐 것만 다시 합니다.
다 깔았는데 뭔가 안 돼요 — 스스로 고칩니다
바탕화면의 volcano-fix 를 누르세요. 살펴보고 고칠 수 있는 것은 알아서 고칩니다.
윈도우는 volcano-fix.ps1 오른쪽 클릭 → [PowerShell에서 실행], 맥은 volcano-fix.command 두 번 누르기입니다.
다 되면 어디서 쓰나요
VS Code 를 열고 왼쪽 Claude 아이콘(또는 Ctrl+Esc / ⌘+Esc)을 누르세요. 바탕화면의 「볼케이노」는 VS Code 없이 쓰실 때의 예비 길입니다.
볼케이노가 「승인이 필요하다」고 해요
로그인한 메일로 볼케이노 운영자의 승인이 나면 바로 쓰실 수 있습니다. 따로 하실 일은 없습니다.

막히면 화면을 통째로 찍어 보내 주세요.
